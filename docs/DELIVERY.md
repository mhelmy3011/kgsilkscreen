## ١. الشعار — «The Pull»

حرفي **K وG** في علامة واحدة. مفيش خط محتاج يتثبت، مفيش صورة، مفيش `stroke`.

| الجزء | معناه |
|---|---|
| العمود | قايمة الشاشة |
| الذراع العلوي | يد السكويجي |
| الحد البرتقالي | حد الصفيحة وهو بيسحب الحبر — الاتجاه اللي العين بتمشي فيه |
| الحلقة G | مفتوحة من فوق يمين، فالسحبة بتبان كأنها **بترسم** الحرف |

**ليه الاتجاه ده بالتحديد:** اترسم على ١٦/٢٤/٣٢/٦٤ بكسل. النسخة المؤطرة بقت مربع
فيه خرم تحت ٢٤ بكسل، والنسخة النقطية بقت زغرطة. دي النسخة الوحيدة اللي لسه
مقروءة على ١٦ بكسل — يعني في تاب المتصفح وعلى أيقونة الموبايل.

**المخرجات:** `mark.svg` · `mark-light.svg` · `mark-mono.svg` · `lockup-h.svg` ·
`lockup-h-dark.svg` · `lockup-h-mono.svg` · `lockup-v.svg` · `lockup-v-dark.svg` ·
`wordmark.svg` · `favicon.svg` · `apple-touch-icon.png` · `icon-192/512.png` ·
`icon-maskable-512.png` — وكلها في الموقع بالفعل (نافبار + فوتر + أيقونات + كارت المشاركة).

**الاسم العربي متجهات مش خط.** «كمال جادو» اتحوّل لـ ٢٣ كونتور بـ HarfBuzz، و
`SILK SCREEN` اتحوّل بنفس الطريقة. يعني اللوجو بيطلع شكله واحد على أي جهاز،
حتى لو الخط مش محمّل — وده الفرق بين شعار و«عنوان بخط».

## ٢. الصور — ٣ سلايدات، ٣ لقطات مخصوصة

| # | اللقطة | بتجاوب على |
|---|---|---|
| ١ | ماكرو: الشفرة بتسحب شريط حبر على شبكة سوداء | «إنت مين وبتعمل إيه؟» |
| ٢ | الورشة: شاشات متكومة، لمبة دافية، تذاكر شغل ورقية | «ليه أثق؟» |
| ٣ | ماكرو: الحافة الأمامية للحبر مقطوعة بخط مستقيم | «إيه اللي هوصل له؟» |

**بدون وجوه، وبدون أي حروف مولّدة.** أول نسخة كان فيها تيشيرت مطبوع بحروف
مولّدة — مسحت الصورة كلها وأعدت التوليد، لأن الحروف المولّدة هي أسرع حاجة
بتفضح إن الصفحة «AI». الأدوات والمواد والإضاءة الحقيقية بتدي مصداقية أعلى.

## ٣. الهيرو — سلايدر أصلي، مش مكتبة

`scroll-snap` بتاع المتصفح نفسه. ليه ده مهم على الموبايل:

- السحب بإحساس النظام نفسه — مفيش JS بيعيد اختراع الـ momentum.
- `overscroll-behavior-x: contain` — سحب أفقي ما بيسحبش الصفحة رأسي ولا العكس.
- شغال من غير JS، وبترتيب طبيعي لقارئ الشاشة.
- `100svh` — زرار السلايد الأول **ما بينزلش تحت الشاشة** وشرايط العنوان ظاهرة.
- السلايدات المخفية `inert` + `aria-hidden` — التاب مش بيدخل جواها.

**بدون autoplay** زي ما اتفقنا. الخيار موجود لو غيّرت رأيك:
`data-autoplay="1"` على `<section class="hero">`.

## ٤. الموبايل أولًا — ده الـ USP

المشكلة اللي كانت موجودة وكانت خطيرة: الـ CSS كان **ديسكتوب-فيرست**. الخط
الأساسي `clamp(15px, 1.02vw, 17px)` بيستقر على **١٥px بالظبط** عند ٣٦٠px،
ونصوص الكروت والخطوات كانت **١٣.٢px**. وصورة الهيرو كانت `display:none` تحت
١٠٤٠px — يعني ٩٠٪ من الزوار ما شافوش الصورة أصلًا.

اللي اتعمل:
- **١٧px** نص أساسي على الموبايل، والكلام ما بينزلش تحت ١٥px في أي مكان.
- كل هدف لمس **≥ ٤٤px** (الأزرار ٤٨–٥٢، النافبار والفوتر والأسئلة ونقط السلايدر).
- الأزرار الرئيسية بعرض الشاشة على الموبايل، والثانوي تحتها مش جنبها.
- `touch-action: manipulation` شالت تأخير ٣٠٠ms، و`-webkit-tap-highlight-color`
  شالت الوميض الرمادي.
- تأثيرات الـ hover بقت محصورة في `(hover: hover)` — ما بتعلقش على اللمس.
- استعلامات الوسائط **بتوسّع بس** (٦٠٠ / ٩٠٠ / ١٢٠٠px). أي حاجة بتصغّر على
  الموبايل بقت في الطبقة الأساسية، وده اللي بيمنع المشكلة ترجع.

**`check-mobile.js` بيمنع الرجوع:** لو أي حد كتب قاعدة `max-width` بتصغّر خط
أو مساحة لمس، أو خفى صورة الهيرو على الموبايل، `npm run verify` بيفشل.

## ٥. بنّاء عرض السعر — ٣ لمسات

أكبر سبب إن حد ما بيبعتش رسالة واتساب إنه مش عارف يكتب إيه. دلوقتي: نوع الشغل،
الكمية، الميعاد → رسالة كاملة مكتوبة وجاهزة للإرسال.

**مش widget بـ JS:** الفورم حقيقي (fieldsets + radios + رابط افتراضي شغال)،
فلو السكربت ما اشتغلش، الزرار لسه بيفتح واتساب برسالة عامة. السكربت بيعمل حاجة
واحدة بس: بيحدّث الـ `href`. مفيش أي تخزين، ومفيش أي حاجة بتتبعت لحد.

## ٨. الاختبارات — ١٠ بوابات آلية

```bash
npm test        # الهوية + الموبايل + التباين + الوصول + السلايدر + بنّاء العرض + السكرول
npm run verify  # + الشيدر + سلامة ٩٩ مرجع
npm run budget  # الوزن الحقيقي لكل أصل
npm run build   # البناء الكامل + فحص الـ dist اللي هيروح لهوستنجر
```

| البوابة | بتمنع إيه |

| `check-mobile` | أي قاعدة `max-width` بتصغّر خط أو مساحة لمس، خط أساسي < ١٦px، صورة هيرو مخفية على الموبايل |
| `check-contrast` | أي زوج لون تحت WCAG AA — **لقى ٣ مشاكل حقيقية واتصلحت** |
| `check-a11y` | landmarks، `h1` واحد، ترتيب العناوين، alt، labels، ids مكررة، مراجع aria معلّقة |
| `test-hero` | ٣٢ فحص: الحالة، النقط، الأسهم بمنطق RTL، الكيبورد، إن مفيش autoplay |
| `test-quote` | ٢٩ فحص: ٣ لمسات، تشفير سليم، مفيش تخزين |
| `check-deploy` | `dist/` قابل للنشر فعلًا على هوستنجر (ضغط، كاش، MIME، CSP، 404) |
| `check-fonts` | كل حرف ظاهر مغطّى بـ `unicode-range` لخط مشحون — الأرقام العربية والـ tatweel والرموز |
| `check-firstview` | تركيب الشاشة الأولى من الـ CSS على ٩ مقاسات وقياس التباين تحت كل حرف مرسوم |
| `budget` | أي زيادة في الوزن، ولكل أصل حد أقصى لوحده |

**اللي مش قادر أتحقق منه هنا، وبصراحة:** رسم الشيدر على GPU حقيقي، وأرقام

## ٩. مشاكل حقيقية اتصلحت أثناء التنفيذ

دي حاجات اكتشفتها بالفحص الآلي مش بالعين، وكانت هتعدّي لو سلّمت على طول:

| المشكلة | الأثر لو عدّت |
|---|---|
| `data/business.js` كان في `.gitignore` | أي clone جديد (ونشر هوستنجر) بيفشل في البناء |
| `.htaccess` قديم في جذر الريبو | كان بيطغى على ملف الإعدادات الحقيقي، فالصفحة بتتنقل **بدون ضغط** وبدون MIME للـ AVIF |
| `--paper-mute` بنسبة ٤.٠١:١ | نصوص ١٣–١٥px تحت حد WCAG AA |
| `--line-strong` بنسبة ١.٦٩:١ | حدود الأزرار وخيارات الفورم كانت **مش باينة** عمليًا |
| عنوان `h4` تحت `h2` في الفوتر | قفز مستوى في ترتيب العناوين |
| الشريط السفلي كان بيختفي مع أي حركة لفوق | وميض مزعج مع أي ارتداد بسيط |
| `npm run build` مش idempotent | كل بناء بيقلل جودة الصور المصدر شوية |
| preload لصورة الهيرو القديمة | باندويث بيتحرق على صورة مش مستخدمة |
| **حبر الشاشة كان بيتغطى بصورة الهيرو** | الهيرو الجديد بقى صورة كاملة العرض، فالحبر (اللي هو أصل الحركة في الموقع) كان بيتغطى في أول شاشة — والحل إن الكانفس بقى يظهر تدريجيًا بعد ما تسكرول. تفاصيل تحته |
| **حبيبات الفيلم فوق الصور والكتابة** | `z-index: 60` كان بيحط طبقة حبيبات فوق الهيرو والخطوط — الشاشة كانت بتبان «مغبّرة» بدل ما تبان مطبوعة |
| **سهم `→` مش موجود في أي خط** | على أي جهاز مافيهوش خط بديل، اللينك كان بيطلع مربع فاضي. السهم بقى مرسوم بـ CSS |
| **نص عربي بخط IBM Plex Mono** | الخط لاتيني بس، فكل الـ eyebrow والتسميات كانت بتقع على خط تاني بالصدفة |
| **صورة الهيرو مطفيّة** | `opacity` + scrim تقيل فوق بعض = صورة سودة. الصورة بقت واضحة والسكريم اتظبط على مكان النص |
| **اسم البراند بيتقطع في النص على الديسكتوب** | «كمال جادو» عرضه ٤.٠٣em في Alexandria 900، والـ cap كان ٧.٥rem = ٦٣٩px جوه عمود ٤٦ch ≈ ٥٥٣px. اتظبط على ٥.٥rem |
| **السلايدات ١٠٨٠w مش موجودة** | المصادر كانت ٨٩٦px، فبناء الصور كان بيشيل مقاس ١٠٨٠ بصمت. موبايل ٣x كان بيكبّر ٧٢٠w لـ ٢x |
| **على موبايل قصير (٣٦٠×٦٤٠) النص كان بياخد ٣ أرباع الشاشة** | مفيش scrim يقدر يحمي القدر ده من النص غير إنه يمسح الصورة. صف الأرقام اتشال تحت ٧٠٠px (متكرر تحت في الأقسام) |

### ملاحظة على ترتيب الطبقات (stacking)

الحبر مش hidden ورا المحتوى — الأقسام كلها شفافة، فالكانفس باين منها. اللي
كان بايظ فعلًا حاجتين اتصححوا:

1. **دخول الحبر**: الكانفس بقى يكتب alpha بيطلع من 0.12 في أول شاشة لـ 1 بعد
   ما الهيرو يخرج من الشاشة، والـ alpha ده متوصّل بـ `uDepth` — نفس القيمة اللي
   بتشغّل كل حاجة تانية، فلما تسكرول لفوق بيرجع بالظبط، مافيش state جديد.
2. **حبيبات الفيلم** كانت فوق كل حاجة (`z-index: 60`) وبقت مع الحبر تحته.

الترتيب الحالي: حبر + حبيبات (1) ← المحتوى (2) ← الناف بار (100) ← الشريط
السفلي (120) ← لينك «تخطي للمحتوى» (300).

## ١٠. محتاج منك قبل النشر

1. **رقم الورشة الحقيقي** — `data/business.js` (`phoneE164` + `whatsapp` +
   `phoneDisplay`)، وبعدها `npm run build`. دلوقتي الرقم **placehold** والبناء
   بيطبع تحذير.
2. **العنوان والإحداثيات** لو مختلفين عن اللي في `data/business.js`.
3. **مراجعة نصوص الالتزامات** — أنا كتبتها من منطق الشغل، لازم تتأكد إنها
   فعلًا اللي بتعملوه (خصوصًا مدة التسليم ٢–٥ أيام وأقل كمية ٢٥ قطعة).
4. **صور شغل حقيقي** لما يبقى متاح — حطها في `assets-src/img` وشغّل
   `npm run build`. الصور المولّدة بديل كويس، بس صور الشغل الحقيقي أقوى بكتير
   في التحويل وفي الـ GEO.
5. **Google Business Profile** بنفس الـ NAP — أقوى إشارة محلية، وتغذّي ظهورك في
   نتائج البحث بالذكاء الاصطناعي.

## ١١. إضافة ٢٠٢٦ — طقم صور جديد + مختبر الخامات 3D

### الصور

- **١٥ صورة** بإخراج فني واحد (تيل/عنبر، نفس العدسة والإضاءة): ٣ هيرو، ٦ خدمات،
  ٦ ماكرو للخامات. مفيش أي حروف أو لوجوهات مولّدة جوه الصورة — ده كان أكبر
  سبب يخلي الصور القديمة تبان «AI».
- المصادر بقت `jpg` بجودة ٩٢ و٤:٤:٤ (أصغر ٥ مرات من PNG ومش بتتعرض لتصغير
  الـ٢٥٦ لون اللي كان بيبهدل الصور الفوتوغرافية). خط الصور بقى يفهم الاتنين.
- كل مقاس متولّد من نفس المصدر: ٣٦٠/٥٤٠/٧٢٠ للهيرو، ٦٤٠/٩٦٠/١٢٨٠ للخدمات،
  ٤٠٠/٦٤٠/٩٠٠ للماكرو. الـ`srcset` في HTML متطابق مع اللي بيتولّد فعلًا
  (كان فيه إشارات لمقاس ١٠٨٠ مش موجود).
- كارت المشاركة (`og.jpg`) اتعاد رسمه من اللقطة الجديدة بنفس محرك HarfBuzz.

> **أمانة قبل النشر:** الصور دي **متولّدة بإخراج فني**، مش لقطات من الورشة.
> استخدمها كـart direction لحد ما تتصور الورشة بنفس الزوايا؛ الصورة الحقيقية
> هتفضل أقوى في التحويل وفي الـGEO.

### المختبر 3D (`#materials`)

- ٦ كروت على أسطوانة `preserve-3d`، زاوية واحدة على الـrig، سحب/أزرار/شرائح.
- بدون JS أو بدون `preserve-3d`: شبكة عمودين بنفس الصور — مفيش محتوى مخفي.
- حلقة الرسم مشتركة مع المحرك (`KGS.engine.addFrame`) وبتشتغل بس لما القسم يظهر.
- كروت الخدمات بقت tilt حقيقي (`rotateX/rotateY` ≤ ٧°) والهيرو parallax ١٦px.
- `prefers-reduced-motion`: مفيش drift/tilt/انتقال، والأزرار بتغيّر الكارت فورًا.
- بوابة جديدة: `node scripts/test-lab.js` (ضمن `npm test`).
