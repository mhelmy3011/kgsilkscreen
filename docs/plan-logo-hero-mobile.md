## ٠. ملخص القرارات (TL;DR)

| البند | القرار المقترح | ليه |
|---|---|---|
| الشعار | **مونوجرام K+G مبني على «الشاشة + الشفرة»**، بشبكة ١٢×١٢، يُسلَّم كـ **paths** (بدون خط) | يشتغل عند ١٦px وفي الطباعة، وبيقول للمجال مش مجرد حروف |

## ١. ما وجدته فعلًا (تشخيص بالأرقام)

فحصت الكود الحالي قبل أي قرار. خمس حقائق لازم تتغير:

### ١.١ الموبايل مش أولوية — الصورة مخفية بالكامل
```css
/* public/assets/css/kgs.css:644 */
@media (max-width: 1039px) { .hero__media { display: none; } }
```
**٩٠٪ من زوارك مش بيشوفوا ولا صورة في الهيرو.** المكان الوحيد اللي فيه صورة على الموبايل هو كروت الخدمات. أي «هيرو سلايدات» جديد لازم يبدأ من العمودي.

### ١.٢ الـ CSS ديسكتوب‑فيرست
| قياس | القيمة |
|---|---|
| قواعد أساسية بـ `min-block-size: 100svh` | تنطبق على كل المقاسات |
| استعلامات `max-width` (patch فوق ديسكتوب) | **١٧** |
| استعلامات `min-width` (تصاعد طبيعي) | ١٤ |
| كتلة `@media (max-width: 640px)` | سطر ١٣٢٨ — إصلاحات فوق الأصل |

يعني الموبايل = ديسكتوب + ١٧ ترقيع. **ده اللي بيخلي تحسين «أفضل تجربة موبايل» مستحيل بدون إعادة بناء.**

### ١.٣ حجم خط المتن على ٣٦٠px = ١٥px بالظبط
```
clamp(15px, 1.02vw, 17px) عند 360px = 15.00px
```
١٥px مقبول، بس مع Cairo/Alexandria العربي والـ line-height ١.٨ بيبقى ضيق. **المعيار على الموبايل ١٦–١٧px.**

### ١.٤ الهوية الحالية مش شعار
- `favicon.svg` = «K» مائل + مربع — مفيش G، ومفيش أي إشارة للسلك سكرين.
- **مكرّر inline في مكانين** (سطر ٧١ نفبار + ٥٥٣ فوتر) = صيانة يدوية لكل تعديل.
- `site.webmanifest` فيه أيقونة SVG واحدة بـ `purpose: any maskable` — **ده غلط تقنيًا**: maskable محتاج منطقة آمنة ٨٠٪ وإلا أندرويد بيقص الشعار.
- `apple-touch-icon` بيشاور على SVG — **iOS مابيدعمهوش**، فالأيقونة مش هتظهر على شاشة الآيفون.

### ١.٥ الهيرو الحالي عريض ومش «مؤسسي»
- `H1` بحجم `clamp(52px, 11.5vw, 168px)` → على ٣٦٠px = **٥٢px** لاسم من كلمتين. جبار في اللوكالة، لكن بياخد نصف الشاشة قبل ما الزائر يعرف إنت بتعمل إيه.
- مفيش أي «دليل خبرة» في أول شاشة غير ٤ أرقام صغيرة.
- مفيش CTA في منطقة الإبهام (كل الأزرار فوق).

### ١.٦ ✅ خطر أزلته قبل ما أوعد بيه
الشعار لازم يحتوي «كمال جادو» بالعربي. أي SVG فيه `<text>` بيعتمد على خط موجود على جهاز الزائر → بيبوظ. **جربت فعلًا** استخراج الكلمة كـ outlines من Alexandria 900:
```
glyphs: 8 | contours: 23 | units wide: 5327 | svg: 3.3 KB
x-range: -311 … 5216  (الحرف «و» بيخرج بره الـ advance — لازم viewBox أوسع)
HarfBuzz+FT bbox: 0 … 5277  ✔ متوافق
```
يعني **الشعار هيبقى vector نقي مستقل تمامًا، حجمه ٣–٦ ك.ب، بدون أي خط**. (اتأكدت كمان إن Alexandria فيها الأرقام الهندية ٠–٩ والفواصل العربية.)

## ٢. الشعار

### ٢.١ الاستراتيجية
المونوجرام لازم يشتغل في ٣ سياقات متعارضة:

| السياق | القيد |
|---|---|
| فافيكون ١٦×١٦ | لازم يقرأ كشكل، مش كحروف |
| نفبار ٣٢px | لازم يبان K وG |
| أيقونة تطبيق + لافتة الورشة | لازم يتحمّل التكبير والمحو |

معظم مونوجرامات «K+G» بتبقى حرفين متلاصقين — وده اللي بيخلي الشكل عام ومكرر. الحل: **الحروف تطلع من أدوات المهنة**.

### ٢.٢ ثلاثة اتجاهات

**الاتجاه A — «الشبكة والشفرة» (المُوصى به)**
- إطار مربع = شاسيه الشاشة (السلك سكرين).
- العمود الرأسي للـ K = حرف الشاسيه.
- ذراعا الـ K = **مقبض الشفرة + حدّها**، بزاوية ١٥° (إحساس الحركة).
- **فتحة الـ G** = الفراغ الحبر اللي بيسيبه الحدّ جوه الإطار — الـ G بيظهر من الـ negative space مش من رسمة.
- بناء على شبكة ١٢×١٢، سماكة stroke واحدة (١.٥ وحدة).
- **بيشتغل عند ١٦px** لأنه هندسي وبتفاصيل قليلة.

**الاتجاه B — «الجَرّة»**: K+G كخط واحد متصل كأنه حبر مسحوب. دافي وإنساني، ممتاز للورشة، **بس بيضيع تحت ٢٤px**.

**الاتجاه C — «البصمة»**: K جوه حقل نقط نصفية، والـ G بيتكوّن من تلاشي النقط. أجملهم في اللوكالة، **الأسوأ في الفافيكون**.

> **توصيتي: A، مع لمسة من حركة B في ذراع الشفرة.** الأولوية للقراءة، والتعبير يجي بعدها — ده فرق الشغل المخضرم عن اللوجو «الفني».

### ٢.٣ مواصفات التنفيذ (A)

```
الشبكة:        12×12 وحدة · viewBox "0 0 48 48" (٤ وحدات قياس)
السماكة:       6px عند 48 (نسبة 12.5%)
الزوايا:       حادة عند الالتقاء، نصف قطر 1.5px عند الأطراف فقط
الـ G:         مضمار (aperture) بعرض 9px، مفتوح من أعلى اليمين (RTL‑aware)
الزاوية:       ذراع الشفرة 15° من الأفقي
المنطقة الآمنة: ٤px حول الشكل لكل الجهات
```

**ألوان (من توكنز الموقع):**
- `#ff5a1f` → الفرشة/حدّ الشفرة (الأكسنت الوحيد)
- `#eef3f1` → الإطار والحروف (على الخلفية الغامقة)
- `#04070a` → نسخة أحادية للورق (طباعة فاتحة)

**قواعد:**
- اللون الواحد مسموح (نسخة mono للطباعة والفافيكون).
- ممنوع: تدرّج على الحروف · ظل · دوران · إضافة نص جوه الشكل.
- الحد الأدنى: **٢٤px رقمي · ٨mm مطبوع**.
- المساحة الحرة = ارتفاع فتحة الـ G من كل جهة.

### ٣.١ المبدأ
كل سلايد بيجاوب على سؤال واحد في دماغ الزائر، بالترتيب:

| # | سؤال الزائر | وظيفة السلايد | الخلفية |

### ٣.٣ إدارة السلايد على الموبايل — القرار التقني

**مش JS carousel.** استخدام **CSS Scroll‑Snap أفقي أصلي**:

```css
.hero-slider {
  display: flex;
  overflow-x: auto;
  scroll-snap-type: x mandatory;      /* سحب أصلي، inertia من النظام */
  overscroll-behavior-x: contain;     /* ميمنع سحب الصفحة */
  scrollbar-width: none;
  direction: rtl;                      /* البداية من اليمين */
}
.hero-slide { flex: 0 0 100%; scroll-snap-align: center; }
```

**ليه ده أحسن من أي مكتبة:**
| المشكلة في مكتبات السلايدر | الحل هنا |
|---|---|
| سحب بعيد عن إصبع الموبايل | السحب نفسه هو سكرول النظام |
| تعارض سحب أفقي/رأسي | `overscroll-behavior` بيحل التعارض |
| قارئ الشاشة بيلخبط | عناصر حقيقية في DOM، ترتيب طبيعي |
| JS بطيء = سلايدر ميت | شغال حتى بدون JS |
| CLS عند التحميل | مفيش إعادة حساب، ارتفاع ثابت |

**المزامنة:** `IntersectionObserver` (threshold 0.6) بيحدّث النقط + `aria-selected`. **الأسهم على الديسكتوب فقط**، ومعاها دعم لوحة المفاتيح (`ArrowLeft/Right` بمنطق RTL: يمين = السابق).

**قرار: بدون Autoplay.** سبب مقنع: كل دراسة على سلايدرات الصفحة الرئيسية بتورّي إن التمرير التلقائي بيخفض الـ CTR على السلايدالتانية، وبيزود الـ CLS، وبيزعّج مستخدمي الـ prefers‑reduced‑motion. هسيب خيار `data-autoplay="0"` جاهز لو غيّرت رأيك.

### ٣.٤ التصميم البصري — «مش AI»

الفرق بين صفحة AI وصفحة مصمم مش في التقنية، في **٥ تفاصيل**:

| قاعدة | التنفيذ هنا |
|---|---|
| **عدم التماثل** | الصورة بتاخد ٥٥٪ من العرض على الموبايل والكلام مرمي فوقها من تحت، مش فوق بعضه في الوسط |
| **طبقة ملمس** | حبيبات فيلم + شبكة السلك سكرين فوق الصورة (بدأناها في الشيدر) |
| **علامات الطباعة** | علامات تسجيل (○＋) في الأركان — توقيع بيعرّف الورشة |
| **الطباعة تحكم** | الـ H1 بيلمس حافة الشاشة، والأرقام بـ mono، والسطر الأخير بس بأكسنت |
| **صفر كلiché** | لا فقاعات بنفسجية، لا glassmorphism على كل حاجة، لا emoji، لا «نحن نقدم أفضل الخدمات» |

**سلم الطباعة الجديد (Mobile‑First):**

| العنصر | ٣٦٠px | ٧٦٨px | ≥١٢٨٠px |
|---|---|---|---|
| H1 | 40px / 1.02 | 64px | 96px |
| H2 | 28px / 1.12 | 40px | 56px |
| متن | **17px / 1.7** | 17px | 18px |
| صغير | 13px | 13px | 13px |
| mono label | 10.5px / 0.16em | 11px | 11px |
| عرض السطر | ≤ 38ch (موبايل) | ≤ 50ch | ≤ 58ch |

### ٣.٥ الخلفية: الشيدر مع الصورة؟
**نعم، بشرط.** الصورة هي البطل، والشيدر يبقى *جو* حولها مش فوقها:
- الصورة بـ `--slide-img` والشفافية ٥٥–٧٥٪ + تدرّج غامق من تحت.
- الشيدر يفضل في المساحات الفاضية فقط (فوق وتحت النص)، دقة ٧٠٪ على الموبايل.
- عند `data-perf="canvas-off"` الصورة لوحدها — والتصميم لازم يبقى حلو في الحالة دي (هختبره).

**قرار: بدون وجوه بشرية.** الوجوه المولّدة هي أسرع حاجة تفضح إن الصفحة «AI». إيدين وأدوات ومواد بتدي مصداقية أعلى وتفادي المنطقة المرعبة.

### ٤.٢ خط الإنتاج
1. توليد المصادر (PNG 1408×768 حاليًا → هطلب **أعمدة ١١٥٢×1536** للسلايدات).
2. توسيع `scripts/build-images.js`: مقاسات `[360, 480, 720, 1080, 1440]` + كشف الأبعاد من الملف بدل ثابت.
3. AVIF (٥٢) → WebP (٧٦) → JPEG (٨٢) + LQIP ٢٤px.
4. **حجم الريبو**: المصادر دلوقتي ١٨ م.ب، والـ `.git` ٢١ م.ب. ٧ صور × ٢.٥ م.ب إضافية = خطر على سقف الـ ١٢٨ م.ب. **الخطة:** بعد التوليد أحوّل المصادر لـ PNG‑8/WebP (≈ ٣٠٠ ك.ب لكل صورة) وأحتفظ بالأصل في `assets-src/original/` مستثنى من git.

## ٥. إعادة بناء Mobile‑First

### ٥.١ الاستراتيجية
بدل ١٧ `max-width`، **٤ نقاط تصاعدية فقط**:

```
base            →  ٣٦٠px وما فوقها   (كل التصميم يبدأ هنا)
@media (min-width: 480px)   →  موبايل كبير / أفقي
@media (min-width: 768px)   →  تابلت
@media (min-width: 1024px)  →  ديسكتوب
@media (min-width: 1440px)  →  شاشات كبيرة
```
أي `max-width` تفضل لازم تكون **استثناء موثّق** (زي `(max-height: 520px) and (orientation: landscape)`).

### ٥.٢ قائمة تحسينات الموبايل (كل واحدة بمعيار قبول)

| # | التحسين | معيار القبول |
|---|---|---|
| 1 | شريط سفلي ثابت: واتساب + اتصال | ارتفاع ≥ ٥٦px · `env(safe-area-inset-bottom)` · `body{padding-block-end}` بيمنع التغطية |
| 2 | منطقة الإبهام: الـ CTA الأساسي في آخر ٣٣٪ من الشاشة | القياس من `getBoundingClientRect` |
| 3 | سلايدر Scroll‑Snap | يشتغل بإصبع واحد، بدون JS، بدون قفزة |
| 4 | صور عمودية | `aspect-ratio` ثابت → **CLS = 0** |
| 5 | خط المتن ١٧px | `font-size` محسوب ≥ ١٦px عند ٣٦٠px |
| 6 | أهداف لمس ≥ ٤٤×٤٤ | كل `a`/`button` في الموبايل |
| 7 | تعطيل `hover` على التاتش | `@media (hover: none)` يلغي كل transform |
| 8 | ارتفاع الهيرو ثابت | `100svh` (مش `dvh` — `dvh` بيسبب إعادة حساب أثناء السكرول) |
| 9 | احترام تقليل الحركة | بدون تشغيل تلقائي، بدون انتقالات > ٢٠٠ms |
| 10 | `prefers-color-scheme` | الموقع غامق دائمًا — بس أضمن التباين، مفيش «ثيم فاتح» مكسور |
| 11 | لوحة المفاتيح + قارئ الشاشة | أسهم ← → بتتنقل، `aria-selected` مظبوط، تركيز مرئي |
| 12 | هابتيك خفيف عند تغيير السلايد | `navigator.vibrate(8)` لو مدعوم (اختياري) |
| 13 | منع تكبير الإدخال في iOS | أي `input` ≥ ١٦px (مفيش حالياً) |
| 14 | شبكة 3G | أول نص يظهر قبل أي صورة (`font-display: swap` + `preconnect` مش محتاج) |

### ٥.٣ «أفضل تجربة موبايل» — الحاجة اللي هتفرق فعلًا
**باني عرض السعر في ٣ لمسات** (بدون كتابة حرف):
```
[نوع: تيشيرت | يونيفورم | أعلام | زجاج | كرتون]
[الكمية: ٢٥ · ٥٠ · ١٠٠ · ٢٥٠ · +٥٠٠]
[اللون: ١ · ٢ · ٣+]        →  واتساب برسالة جاهزة
```
بتتولّد رسالة `wa.me` فيها كل التفاصيل. **مفيش باك‑إند، مفيش فورم، مفيش `input`.** دي أقوى ميزة UX ممكن تقدمها لورشة في مصر — وبتخليك مختلف عن أي حد تاني في المحافظة.
*(مقترحة كمرحلة ٥ — مستقلة، ممكن تتأجل)*

## ٩. قرارات محتاجها منك

1. **اتجاه الشعار**: A (الشبكة والشفرة) / B (الجرة) / C (البصمة) / عندك مرجع.
2. **الصور**: بدون وجوه (توصيتي) / بأشخاص / مزيج.
3. **خلفية الهيرو**: الشيدر + الصور (توصيتي) / صور فقط (أسرع) / شيدر فقط (أفخم).
4. **تشغيل السلايدات**: بدون (توصيتي) / تلقائي كل ٧ ثواني / تلقائي على الديسكتوب فقط.
5. **عرض السعر في ٣ لمسات** (مرحلة ٥): نعم / لاحقًا / لا.

## ١٠. ملاحظة أخيرة كاستشاري

أكبر مكسب في المشروع ده مش الشعار ولا الصور — **هو إن الموبايل يبقى مبنى من الأول**. دلوقتي الصفحة ديسكتوب مضغوط في شاشة صغيرة، والصور مخفية. بعد المرحلة ٤، الصفحة هتبقى اتصممت على ٣٦٠px واتوسّعت — وده الفرق اللي الزائر بيحسه من غير ما يعرف يسميه.

الـ USP اللي هيخلّيك مختلف مش «أحلى صفحة» — هو **إن أي حد يفتحها على موبايل قديم في أبو كبير يلاقيها سريعة، واضحة، وبزرار واحد يوصله ليك**.
