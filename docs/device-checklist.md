# قائمة الفحص على موبايل حقيقي

البيئة اللي بتبني فيها الصفحة **مفيهاش متصفح**، فحاجات زي رسم الشيدر على GPU،
والـ Lighthouse، وإحساس السحب بالإصبع — مش قادر أتحقق منها. دي القائمة اللي
تخلصها في ١٠ دقايق على تليفونك قبل ما تقول إنها خلصت.

**الأجهزة المستهدفة بالترتيب:** أندرويد متوسط (٣٦٠–٤١٢px، ٣G/4G) · آيفون صغير
(SE / ٣٧٥px) · آباد ٧٦٨px · لابتوب.

## لو حاجة فشلت

الأغلب تكون واحدة من دول:

- **السلايدر بيرجع نص سلايد** → `scroll-snap-stop: always` اتشال من `.hero__slide`.
- **زرار السلايد الأول تحت الشاشة** → `.hero` بقى `100vh` بدل `100svh`.
- **الشريط السفلي بيغطي حاجة** → `padding-block-end` بتاع `.footer` اتغيّر.
- **الصور تقيلة** → `npm run images` وبعدها `npm run budget`، وشوف أنهي صورة عدّت الحد.
- **الخط مش بيظهر** → `npm run fonts` (الملفات في `public/assets/fonts`).

الفحوصات الآلية بتشتغل بأمر واحد:

```bash
npm test && npm run verify && npm run budget
```
