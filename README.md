# كمال جادو — سلك سكرين · kgsilkscreen.store

صفحة هبوط عربية (RTL) لورشة سلك سكرين في **أبو كبير، محافظة الشرقية** — بتصميم
**ورق دافئ وحبر داكن** (Light / Paper) وحركة مبنية على `transform` و`opacity` فقط.
المشروع Node.js خفيف بيشتغل على **استضافة هوستنجر المشتركة**.

---

## ١. التشغيل

```bash
npm install
npm run dev     # http://localhost:3000
```

## ٢. النشر على هوستنجر

### المسار (أ) — Node.js ✅ الموصى به

1. hPanel → **Advanced → Node.js → Create application**
   - Application root: `kgsilkscreen` (جوه `domains/kgsilkscreen.store/`)
   - Startup file: `server.js` · Node: **18 أو 20**
2. ارفع الملفات **بدون** `node_modules` و**بدون** `dist`.
3. اضغط **Run NPM Install** ثم **Restart**.
4. اتأكد إن `https://kgsilkscreen.store/api/health` بيرجع JSON.
5. فعّل SSL من hPanel.

> السيرفر بيقرأ `PORT` من متغيرات هوستنجر تلقائيًا. مفيش أي إعداد إضافي.
> لو نسيت تعمل build، السيرفر بيشتغل عادي على `home.html` بدون SSG — الصفحة شغالة في الحالتين.

### المسار (ب) — استضافة ثابتة (لو Node.js مش متاحة)

```bash
npm run build
```

ارفع **محتويات** `dist/` جوه `public_html`. ملف `.htaccess` بيتنسخ معاهم أوتوماتيك
(ضغط + كاش + صفحة ٤٠٤).

> ملاحظة: في الاستضافة الثابتة، `/` لازم يكون اسمه `index.html`. الـ SSG بيكتب
> `dist/index.html` والنسخة الأصلية بتبقى `dist/home.html` — فالاتنين شغالين.

### DNS

Nameservers بتاعة هوستنجر، أو `A record` لـ IP الاستضافة. بعد التحويل فعّل HTTPS.

## ٤. التصميم والحركة

### الفكرة: ورق مطبوع، مش شاشة مضيئة

النسخة الحالية **فاتحة بالكامل**: خلفية ورق دافئ (`--paper-0`)، حبر داكن للنص
(`--ink-0`)، ومسحة صبغة واحدة (`--pigment`). صورة الهيرو بقت **كارت مطبوع مؤطّر**
في عمود مستقل على الجريد — مش صورة تحت النص — فالتباين معروف قبل ما أي حاجة تترسم،
ومفيش scrim بيتغطى على الصورة ولا على الكلام.

### قواعد الحركة

1. **مفيش حلقة رسم دائمة.** الحركة المرتبطة بالسكرول بتشتغل بـ rAF واحد لكل دفعة
   سكرول؛ لو الصفحة ساكنة مفيش أي شغل.
2. **الدخول مرة واحدة.** `IntersectionObserver` بيضيف `.is-in` وبعدها يلغي المراقبة،
   فمفيش إعادة تشغيل عند الرجوع لفوق ولا قيم محفوظة تتفرقع.
3. **كل حاجة `transform` / `opacity`.** مفيش `top` ولا `width` ولا blur متحرك،
   فالكومبوزيتور هو اللي بيشتغل مش الـ main thread.
4. **تأثيرات المؤشر للمؤشرات الدقيقة فقط.** اللمس (`hover: none`) مالوش أي listeners
   زيادة، و`prefers-reduced-motion` بيوقف كل الحركة ويظهر المحتوى فورًا.
5. **`kgs` بيقفل نفسه لو ماوصلش.** سكربت صغير في `<head>` بيشيل `.js` بعد ٢.٦ ثانية
   لو ملف الحركة ما اتحمّلش — الصفحة تفضل مقروءة بالكامل، وكل الروابط شغالة.

### الطبقات

| الطبقة | التقنية | الوظيفة |
|---|---|---|
| `kgs-motion.js` | IO + rAF واحد | الكشف المتدرج، العدادات، شريط التقدم، زر واتساب العائم، اللمعان والمغناطيسية |
| `kgs-hero.js` | scroll-snap أصلي | سلايدر ٣ لقطات بمنطق RTL، بدون autoplay، مع `inert` للمخفي |
| `kgs-quote.js` | DOM | بنّاء عرض السعر (٣ لمسات → رسالة واتساب) |

مفيش WebGL ولا canvas ولا شيدر في النسخة دي: الحبر بقى **لون وورق وملمس CSS**،
وده اللي خلّى أول شاشة تنزل من ~٧٥ ك.ب JS إلى ~٧ ك.ب.

## ٥. الأداء — أرقام مقاسة مش مُدَّعاة

`npm run budget` بيقيس اللي بيتنزّل فعلًا على السلك (brotli):

```
✓ Mobile 360×800  · first view — 63.8 KB
✓ Desktop 1440×900 · first view — 71.7 KB
   HTML 17.1 KB · CSS 8.1 KB · JS 7.1 KB · خطوط 26.0 KB · صورة 5.3 KB
```

| القرار | الأثر |
|---|---|
| صفر framework (لا React ولا GSAP) | لا hydration ولا bundle |
| **شيل محرك WebGL** (٣ ملفات، ~٢٦ ك.ب) | ملف حركة واحد ٣.٤ ك.ب مضغوط |
| **صفر `backdrop-filter`** | النافبار والزر العائم شفافين بحد رفيع وظل — نفس الشكل بدون تكلفة GPU |
| خلفية من gradients ثابتة + حبيبات SVG مضمّنة | صفر صور خلفية وصفر طلبات إضافية |
| **خطوط محلية** + preload + `unicode-range` | صفر طلبات لـ Google Fonts (مهم جدًا على شبكات مصر) |
| CSS مصغّر (50.8 ك.ب → 8.1 ك.ب مضغوط) | أسرع وأرخص |
| **critical CSS مضمّن** + الباقي `media="print"` swap | أول رسم مايستناش الستايل شيت |
| brotli من السيرفر | HTML 82 ك.ب → **17.1 ك.ب** |
| AVIF أولًا ثم WebP ثم JPEG + `srcset`/`sizes` + أبعاد صريحة | أقل وزن بأحسن جودة وصفر CLS |
| lazy للصور تحت الشاشة + preload واحد للـ LCP | صور السلايدين ٢ و٣ مش جزء من أول شاشة |

## ٦. SEO و GEO

### الـ SEO
- `<title>` و`description` بالكلمات اللي الناس بتدور بيها فعلًا (سلك سكرين، طباعة تيشيرتات، يونيفورم مدارس، أبو كبير، الشرقية).
- Canonical + Open Graph + Twitter Card + `og:image` مربوطة بكارت مشاركة **مرسوم بخط الموقع**.
- HTML ثابت بالكامل (SSG) — المحتوى كله موجود قبل أي جافاسكريبت.
- صور بـ `alt` وصفي عربي + `width/height` + `srcset`.
- `sitemap.xml` (بصور) + `robots.txt` بيستثني صفحات النماذج الأولية.
- JSON-LD: `LocalBusiness` + `PrintShop` + `OfferCatalog` + `FAQPage` + `WebSite`.

### الـ GEO (الظهور في البحث والمساعدين المحليين)
عشان الورشة تظهر لما حد يسأل «مين بيطبع تيشيرتات في الشرقية؟»:

1. `geo.position` و`geo.placename` في الميتا + `GeoCoordinates` في JSON-LD.
2. `areaServed` مكتوبة بأسماء المدن (أبو كبير، الزقازيق، بلبيس، منيا القمح، فاقوس) لا بـ «الشرقية» بس.
3. `openingHoursSpecification` بصيغة ISO.
4. `FAQPage` — ده اللي بيخلي جوجل والمساعدين يقتبسوا إجابات مباشرة.
5. محتوى بلغة محلية طبيعية (أبو كبير، ميرش، يونيفورم، جملة) — ده اللي بيفرق في البحث المحلي.

**الخطوة اللي بعد ده:** اعمل Google Business Profile للورشة بنفس الاسم والعنوان والرقم
بالظبط زي الموقع (NAP متطابق)، وحط الرابط. ده أقوى إشارة GEO محلية موجودة.

### قياس
`window.KGS.vitals` بعد أي تجربة بيرجع `{ lcp, cls, inp, ttfb }`.
مش بيتبعت لأي سيرفر — للاستخدام في الكونسول أو اختباراتك.

## ١٠. ملاحظات تقنية معروفة

- **الخطوط**: Tajawal مقسوم عربي/لاتيني. أي نص بيخلط الاتنين بيعتمد على
  `unicode-range` في CSS — لو أضفت لغة تالتة، ضيف ملف subset و`@font-face` ليها.
- **الشريط المتحرك**: الحاوية RTL والحركة `translate3d(+50%)` لأن التراك يبدأ من
  الحافة اليمين ويمتد شمالًا؛ عكس الإشارة بيطلّع النص بره الشاشة على الموبايل.
- **RTL + `transform`**: كل الحركات الأفقية متعمدة على محور X فقط، والمحتوى نفسه
  بيستخدم خصائص `inset-inline-*` فمفيش قلب للاتجاه.
- **`prefers-reduced-motion`**: مش مجرد تعطيل — بيظهر كل عناصر الكشف فورًا ويوقف
  الشريط والهالة، فالمحتوى بيفضل كامل بدون أي حركة.
