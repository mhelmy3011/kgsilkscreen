# الهوية البصرية — كمال جادو

الهوية كلها **متجهات مبنية بالكود**، مفيش فيها خط محتاج يتثبت، ولا صورة نقطية،
ولا `stroke`. ده مش ترف — ده اللي بيخلي اللوجو يبان صح من 16 بكسل لحد لافتة
المحل، ومن غير ما يتغير شكله لو الخط مش محمّل.

## العلامة: "The Pull" (السحبة)

| الجزء | معناه |
|---|---|
| العمود | قايمة الشاشة (الفرام) |
| الذراع العلوي | يد السكويجي |
| الحد السفلي البرتقالي | حد الصفيحة وهو بيسحب الحبر — لون واحد بس، عشان العين تعرف اتجاه الحركة |
| الحلقة (G) | حرف G مفتوح من فوق يمين، فالسحبة بتبان كأنها **بترسم** الحرف |

الخيار ده اتقرر بالتجربة مش بالذوق: رُسم على 16/24/32/64 بكسل. النسخة المؤطرة (A)
بقت مربع فيه خرم تحت 24 بكسل، والنسخة النقطية (C) بقت زغرطة. الاتنين محفوظين
كمراجع في `alt-a.svg` و `alt-c.svg` بس مش مستخدمين.

## القواعد الثابتة

1. **مفيش `<text>`.** أي نص في اللوجو بيبقى مسار. لو الخط مش موجود، الشكل ما يتغيرش.
2. **مفيش `transform` ولا `<g>`.** كل تحويل محروق جوه إحداثيات المسار، فالشكل بيطلع
   زي ما هو في الإيميلات وملفات الـ PDF والأدوات اللي بتفهم المسارات المستوية بس.
3. **مفيش `stroke`.** أشكال مليانة بس — الخطوط بتضيع على 16 بكسل.
4. **البرتقالي لون واحد.** `#ff5a1f` على الغامق، `#c22f0a` على الفاتح (لتباين AA).

## إعادة التوليد

```bash
npm run logo          # العلامة + الأقفال + الأيقونات
npm run check:logo    # بيتأكد إن كل القواعد فوق لسه محترمة
```

`check:logo` جزء من `npm run verify`، فلو حد كسر قاعدة، البيلد بيفشل.
